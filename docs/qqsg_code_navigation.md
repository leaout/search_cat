## 代码是什么

这是客户端可解析的坐标超链接，不是Python/Lua程序，也不需要修改游戏内存：

```text
/<DnpcWalkEx=地图ID|原始X|原始Y>/123456</C04>
```

`123456`是显示并点击的链接文字，不是账号。地图ID来自当前客户端的
`res/Txt/MapData.txt`；原始X/Y不是鼠标屏幕坐标。
历史实现使用小地图坐标乘100，例如(13,16)变成(1300,1600)。
从SRV解析出来的出口坐标已经是原始单位，不能再乘100。

本仓库提交 `45bdbc9` 的官爵插件 `_navigate_by_code()` 已实现此方式；
`58fa42b` 改用地形/任务栏寻路时将其移除。此次恢复使用同样的命令格式。
独立原始资料：[用按键精灵玩QQ三国·自动寻路思路](https://www.bananaoven.com/articles/99.html)。
资料年代较早；这里仅用于交叉核对格式，不沿用其中的内存地址、旧坐标或寻路限制。

## 怎样使用

1. F4打开交流，选择好友，点击添加。
2. 在“请输入添加好友的名称”输入框粘贴一条完整命令。
3. 看到生成的 `123456` 链接后，点击这个链接。
4. 取消输入弹窗并关闭交流面板，观察小地图位置是否变化。

**不要点击输入弹窗的“确定”来添加好友，不需要向聊天频道发送代码。**
能生成链接、点击链接、开始移动、到达目标是不同状态；不能合并成“寻路成功”。
原代码按两次Esc收起面板，新版只在确认自己的窗口后点击取消/关闭，不盲按Esc。

## 新版怎样运行

宿主提供单次原子 `window.navigate_by_code`：确认绑定窗口→识别交流页签→
相对定位添加按钮→确认输入提示→粘贴代码→仅在输入区域识别123456→
点击链接→确认取消/关闭。不会点击添加好友的确定按钮。
当前使用原生像素大小、面板平移定位；同一行至少两个不同页签共同校验位置，
不要求“好友”本身一定被OCR读到，也不混入聊天栏里的“军团”。
缩放、布局或OCR不符时失败，不盲点；取消后漏识别面板也不能直接算已收起。
鼠标停放在客户区(8,8)，避免小手遮住链接；临时截图逐帧释放，不长期保留。
交易/道具使用确认窗口会阻止操作。

完整面板事务持有宿主全局前台锁，多窗口不会在输入到点击之间相互插入操作。
这不是后台输入。一次宿主识别事务尚不能中途抢占；停止需等当前宿主调用返回，
之后不继续插件检测。OCR耗时不包含在配置的暂停秒数中。

链接点击后，插件单独读取右上角小地图。两次连续检测到目标地图和目标坐标
邻域才记到达；未知读数或错地图不计成功。到达检测等待时间默认120秒（可配置，上限600秒），
最多180次检测；此计时不包含前面的面板事务，并非硬性总耗时上限，
正在执行的OCR/RPC返回后才能检查超时。超时抛错，不重复生成链接、不猜方向、不按G。
`navigation/current.json`记录命令、目标、最近观测和starting/moving/unknown/arrived/failed；
重启后必须重新观察，不使用历史arrived作为成功依据，也不承诺自动恢复原路径。
停止脚本不等于取消已开始的游戏原生寻路，可能需人工停止角色移动。

### 挖矿插件0.3.3

停止旧脚本，重启**整个Search Cat源码程序**，刷新插件列表。
exe需要重新打包；本次未打包。

推荐首次只绑定一个窗口，配置：

```json
{
  "travel_mode": "code",
  "code_navigation_only": true,
  "code_target_map_id": 907,
  "code_target_x": 1000,
  "code_target_y": 570,
  "code_navigation_timeout": 120,
  "dry_run": true
}
```

先模拟核对日志，再取消模拟验证；仅寻路模式不换线、不购买、不按G。
跨地图矿区测试前需人工准备14线并站在江陵，脚本会核对起点。
也可以把目标先设成55和江陵内的安全坐标，只测同地图链接。
不建议把上述出口点直接用于“到达附近”测试：过图后地图变了，应另外检测传送结果。
正常挖矿需关闭仅寻路模式；默认 `travel_mode: actions` 保留旧路线，启用代码需明确选择code。
正常挖矿的代码目标只允许906/907/908；55/57/131用于单独调试，不能把在江陵停下当成到矿。
即使寻路成功，巡逻仍需 `patrol_route`，矿锄/疲劳检测与购买边界保持原样。

### 官爵插件

`coordinate_navigation_mode: code`启用恢复的坐标代码方式，默认仍是terrain以避免改变旧配置。
`npc_routes`保持 `[地图ID,小地图X,小地图Y]`，这里自动乘100。
目标地图名称从 `navigation_routes` 或当前客户端目录获得。
任务栏NPC仍按 `prefer_task_click_navigation` 的原逻辑优先；代码用于坐标目标，
不会悄悄替换每一次任务栏点击。
