# 行脚六出口测试 0.2.0（实验版）

手动进入“行脚商行馆入口”，站在错误出口送回的真实起点，关闭全景地图。
脚本平台刷新插件后选择“QQ三国行脚六出口测试”，绑定一个窗口，先模拟运行检查配置。
当前使用前台按键，不支持多个角色同时占用键盘。

读取本机 objects.pkg 的平台和攀爬连接，验证六张同名入口地形一致，使用本地地形规划器。
按实时小地图坐标执行短距离行走、跳跃、下落、攀爬，不使用好友代码或游戏内置寻路。
落点偏离重新规划；连续6次不接近路点触发纠偏，超过8次纠偏或连续5次无法识别地图停止。

按顺序最多尝试六个出口，每个默认限时300秒。接近出口最多按一次Up。
离开起点后连续两次确认回到起点才判失败；连续两次确认进入“行脚商行馆”才成功。
超时且仍确认在入口时尝试下一处。全部失败保存 needs_attention，不无限重试。
平台停止按钮结束后续操作，短按键由SDK释放。

map_id默认456，不代表自动识别版本。六张地图地形相同，出口位置略有差异。
exits.json包含456至461的36个原始出口坐标，不可再次乘100；真实出口由游戏动态决定。
progress.json保存本次进度；重新启动重新确认状态，不跳过旧记录出口。

跳跃跨度、高度、移动速度及Down+Space下落尚需实机校准，默认值仅通过离线连通性验证。
本版本不购买物品、不领取奖励、不处理入口NPC对话，不保证默认参数能完成所有跳跃。
