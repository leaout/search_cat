# QQ三国位置读取与原生寻路

在搜索猫的脚本平台刷新插件，选择“QQ三国位置读取与原生寻路”，自动检测并绑定四个游戏窗口。
先模拟运行检查游戏目录；取消模拟后点“启动全部”，每个窗口持续读取小地图名称及显示坐标。
日志和调试变量“当前位置”显示读数，识别失败时当前坐标为空。

默认 `navigate: false`，不移动角色。需要寻路时修改插件 JSON 配置，例如：

```json
{
  "game_directory": "D:\\WeGameApps\\QQ三国",
  "interval": 3,
  "navigate": true,
  "target_map": "秃龙洞口",
  "target_x": 6,
  "target_y": 4
}
```

目标坐标填写小地图显示值。原生寻路接口使用放大 100 倍的内部单位，插件自动换算。
启动全部会让全部绑定角色前往同一个目标。寻路只发起一次，连续两次读取到目标附近才算到达；
失败或超时停止，不自动重试。该入口依赖原生交流面板的识别，当前客户端的真实移动仍需实测。

每个窗口的数据在 `plugin_data/com.searchcat.qqsg.position/sessions/<会话>/data/positions/<窗口句柄>.json`。
读取会依次激活游戏窗口，四个窗口由现有前台调度器串行处理，因此 3 秒是请求间隔，不保证各窗口每 3 秒完成更新。
小地图需可见；目前支持固定 Build36 布局，其他缩放和皮肤可能无法识别。
停止全部后 JSON 是历史记录，使用者应检查 `updated_at`，不能将旧文件当作实时位置。
