# QQ 三国日常任务

这是独立于官爵实验插件的新任务插件。垓下学艺、灭鼠靖仓、举孝廉答题和运送物资均在本插件内执行，使用独立的题库、进度和日志。

在脚本平台中选择本插件，绑定指定游戏窗口后，可以直接使用“日常任务调试”下拉框选择运行模式：

- `完整流程（按任务顺序）`：执行 `task_sequence` 中的全部任务。
- `仅垓下学艺`、`仅灭鼠靖仓`、`仅举孝廉答题`、`仅运送物资`：只执行对应任务，适合先单独验证路线、对话或 OCR。

下拉框会自动保存到插件配置；也可以手动设置 `task_mode` 和 `single_task`。单任务模式会忽略 `task_sequence`，不会继续执行其他日常。

完整流程默认顺序为：

```json
["gai_xia_xue_yi", "mie_shu_jing_cang", "ju_xiao_lian", "transport"]
```

垓下学艺按“大司马 → 霸王城 → 资深学艺导师 → 领取静修凭证 → 开始静修”的流程执行；
灭鼠靖仓按“太仓尉 → 地鼠区域 → TAB 锁定/A 攻击/C 拾取 → 返回提交”的流程执行。
两项任务都会先读取小地图坐标，按 `navigation_routes` 走到对应 NPC 附近，再按 G 接任务；
默认路线是成都子城的大司马 `(10,16)` 和太仓尉 `(28,16)`，其他国家或地图必须先修改路线。
当前首版只执行同地图坐标路线，跨地图路线仍应使用游戏任务栏自动寻路或后续地图连接路线。

灭鼠靖仓的攻击按键默认来自游戏基本操作：TAB 锁定、A 普通攻击、C 拾取，均可在配置中修改。
首次建议启用模拟运行，校准 `task_region` 和等待参数后再执行真实输入。

新增任务的流程依据：[垓下学艺流程说明](https://jingyan.baidu.com/article/a3f121e42e38efbc9152bb63.html)、
[灭鼠靖仓任务说明](https://www.wz1580.com/4068.html)、
[QQ 三国基本操作](https://qqsg.17173.com/xinshou/caozuo.shtml)。不同客户端版本的 NPC 对话和任务计数可能不同，
首次真实运行应保留日志并人工观察。
