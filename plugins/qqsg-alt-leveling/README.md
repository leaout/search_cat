# QQ 三国小号起号

这是一个面向蜀国游侠的独立实验插件，用于把小号从 1 级推进到 50 级。它不把网络攻略中的旧 NPC、坐标和路线写死，而是优先使用当前客户端任务栏自身的 NPC 点击寻路：

1. OCR 读取任务栏和当前等级；
2. 点击任务栏中的 NPC，触发游戏自带寻路；
3. 等待角色到达后激活游戏窗口，按 G 和回车推进对话；
4. 如果任务栏出现 `当前/总数` 进度，执行配置的 `task_action_keys`（默认 A，可替换成游侠技能键）；
5. 识别 `[已完成]` 后再次点击 NPC 并对话提交；
6. 重新扫描任务栏，判断任务是否变化或完成；
7. 进入下一个任务，并把等级、阶段、任务签名写入 `leveling_state.json`。

默认按 1–10、11–20、21–30、31–40、41–50 五个阶段执行。首次使用必须在配置中框选准确的 `task_region` 和 `level_region`，并先开启模拟运行观察日志。模拟运行默认观察 3 轮后暂停，确认 OCR 和点击位置正确后再关闭模拟运行进行实测。

当前版本是客户端优先的通用任务引擎：不同客户端的任务 NPC、战斗操作和跨地图路线差异较大，具体任务动作通过当前运行日志逐步补充。若任务栏没有 NPC，插件可以尝试在当前位置按 G 对话，但不会猜测未知地图路线。`country` 和 `role_class` 用于记录角色配置，当前自动决策仍以游戏实际 OCR 为准。

中断后默认读取上次的 `leveling_state.json` 继续；要重新起号，将 `reset_progress` 改为 `true` 启动，完成重置后再改回 `false`。
