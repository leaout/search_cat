# 地形寻路实验使用说明

打开官爵插件的地图调试，先点选人物与目标；输入框显示的小地图坐标应与游戏一致。
默认倍率 100 仍是假设。吸附后的起点与游戏 OCR 坐标差超过 1 时，测试会拒绝执行。

设置跳远和跳高（地形原始单位），点击规划路线；红色虚线悬停可看步骤。
点击载入寻路测试后，在脚本平台绑定窗口，先模拟运行核对日志，再取消模拟启动。
测试复用平台启动/停止机制，只执行路线，不接任务。恢复任务需将 terrain_test_enabled 设为 false。

算法将类型 2、4 暂作平台，以端点和起终点构造图，优先行走；跨平台在设置的范围内建立候选跳跃边。
下落候选最大高度为 250 原始单位。类型 8 默认关闭，勾选后作为候选攀爬连接。
跳跃边是几何可达假设，尚未检查完整抛物线碰撞、头顶障碍或动态机关；不能保证执行成功。

执行通过短按方向键、跳跃同时按方向、随后 OCR 反馈控制。地图缺失/变化、起点不符、持续卡住或次数超限均停止。
日志记录动作、目标平台编号、坐标偏差和按键时长。NPC 网络点默认隐藏，本次测试应自行点选目标。
标记和跳跃能力变动会清除旧规划，避免载入过期路径。
